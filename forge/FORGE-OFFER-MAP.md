| Free (channel) | Paid / support (Forge) |

## Product listings (site sections)

### 1. Follow the adventure *(primary CTA)*
- Link: YouTube [@Lost-Paradice-Forge](https://www.youtube.com/@Lost-Paradice-Forge) — display **Paradice Miniatures**
- Copy: BA / KotC vs Orks · Tue + Fri cadence · no hard sell
- Site block: latest episode tease + “Watch the crusade”

### 2. Discord *(community)*
- Role: chat builds, list ideas, share prints, Armageddon night
- Gate lightly: open invite *or* Patreon-linked roles later
- Do not require Discord to watch YouTube

### 3. Patreon *(fund the desk)*
**Promise:** Patreon buys plastic, paint, and time — so the adventure continues.

| Tier idea (draft) | ~ | What they get |
|-------------------|---|---------------|
| **Scout** | $3–5 | Name in credits · Discord role · monthly desk note |
| **Crusader** | $8–12 | Early episode looks · army list PDF when locked · vote next Short topic |
| **Forge Patron** | $20+ | STL of the month *or* commission discount · shout-out · tip toward named 2k milestone |

*Paid tutorials:* only as **adventure companion notes** (how *this* list/convert was done) — not a generic “how to paint red” school. Free YouTube stays the craft window.

### 4. Tip a 2,000-point army *(and beyond)*
- Milestone tips: “Help finish BA Liberator Spine 2k” / “Help finish Ork Green Tide + Wagon 2k” / “Unlock 3k Armageddon Host”
- Progress bar on site (manual update is fine at first)
- Stretch: tip toward Lemartes / Scouts / Boyz bricks / second wagon
- Transparency: short monthly note — what the tip bought

### 5. STL files *(terrain & accessories)*
Focus: **centerpiece battlefield environments** people actually put in the middle of the table — not random bitz.

Priority packs (see [`TERRAIN-STL-CHECKLIST.md`](TERRAIN-STL-CHECKLIST.md)):
1. Crashed battleship / void wreck (BA sky aesthetic)
2. Ruined cathedral / shrine (Sanguinius / gothic)
3. Ork scrap fortress / yellow-rust industrial
4. Modular ruin scatter (Armageddon streets)
5. Objective markers · dice trays · token holders (Paradice = dice)

**Pipeline:** wishlist vote → Meshy / Blender / print test → sell STL (personal use license) · optional physical print later.

### 6. Art commissions
- Character portraits · army heraldry · thumbnail art · Equinox-style split faces (if you want crossover mood)
- Clear tiers: bust / half / full scene
- Portfolio link when ready

### 7. Soft links (not the product)
- YouTube (adventure)
- Optional “companion notes” on Patreon (not competing with free tutorials)
